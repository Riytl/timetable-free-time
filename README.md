# 空课 · 课表与空闲时间

独立开发的项目开发部 `pdd-02` 作答项目。使用 Vue 3、TypeScript 和 Vite，从课表数据计算空闲时间。这个仓库与校园工具箱分开交付，拥有独立的代码、依赖和运行入口。

## 本地运行

需要 Node.js 20.19+ 或 22.12+（开发环境为 22.23）。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。生产构建：`npm run build`；类型检查：`npm run typecheck`；算法用例：`npm test`。

## 需求 1：读入课表与本周文本视图

可手动录入课程名、星期、开始和结束时间，也可选择本地 UTF-8 CSV 文件或粘贴 CSV。导入完成后生成完整星期一至星期日的文本课表，可复制或导出 CSV。

```csv
课程名,星期几,开始时间,结束时间
高等数学,1,09:00,09:45
高等数学,1,09:55,10:40
大学英语,3,14:00,15:30
```

也接受 `name,day,start,end` 表头，字段可调整顺序。星期支持 1–7（周一至周日）、中文星期或英文星期；时间必须为 `HH:mm`，结束可写 `24:00`。结束必须晚于开始，跨天课程请拆开。支持 BOM、CRLF、带引号的逗号、双引号转义和字段内换行。

每次导入先验证全部记录，一条错误会阻止整次追加，并指出 CSV 记录号。导入限制为 1 MB、1000 条记录；精确重复项自动跳过。例子见 [timetable-example.csv](timetable-example.csv)。

## 需求 2：每日空闲时间与连续课程

每个星期可配置可用范围，默认 08:00–22:00；最短空档默认 30 分钟，可调 1–1440。将同一天同名课程按开始时间排序，间隔 ≤ 合并阈值（默认 10 分钟）时合并。例如 09:00–09:45 与 09:55–10:40 合并为 09:00–10:40，不产生 10 分钟伪空档；不同名课程之间不填补间隔。

使用半开区间 `[开始,结束)`，先合并连堂课，再裁剪到每日范围，对所有占用区间求并集，最后取补集。重叠、相接课程不重复扣除时间，无课程当天返回整个范围；满课当天返回空列表。课表展示合并结果，CSV 导出保留原始记录；删除合并项会移除其包含的全部原始节次。

手动核对：示例周一 08:00–22:00、最短 1 分钟、阈值 10 → 08:00–09:00、10:40–22:00；阈值改成 0 会额外出现 09:45–09:55。

## 隐私和范围

纯浏览器工具，无账号、后端或课表系统连接。本地文件不会上传，课程数据保存在当前浏览器的 `timetable-free-time:*` 存储键中。只处理每周重复的一周课表；没有学期单双周、节次换算或跨日课程功能。请以实际课表为准。
